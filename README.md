# Raf

A tiny macOS menu bar shelf for files and links, inspired by Dropzone.

- **Drop Bar:** park files and links, drag them out later
- **Folders:** drop to copy or move into your own folders
- **AirDrop:** send to nearby devices
- **Shorten URL:** TinyURL, Bitly, Dub.co, Shlink or YOURLS

Click the menu bar icon to open the shelf, or drag files onto it. Right-click the icon for Settings.

## Build

Requires macOS 13+ and Xcode 15+.

```bash
scripts/build-app.sh && open build/Raf.app
```
